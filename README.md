# بصمة الزمن في الذهب 🕐🥇

اكتشاف الأوقات المتكررة في اليوم التي يتحرك فيها الذهب باتجاه واحد ثابت (صعود/هبوط)
دون انعكاس يُذكر — **بالاعتماد على الزمن فقط**، بلا أخبار ولا مؤشرات ولا أشكال شموع.

اقرأ **[PLAN.md](PLAN.md)** للخطة الكاملة والتعريفات والحماية من "الصيّادين".

## التشغيل السريع
```bash
pip install -r requirements.txt
python analyze_gold_time.py data/XAUUSD_ticks.csv
```
النتائج تظهر في `out/tf1/`, `out/tf5/`, `out/tf15/`.

## شكل البيانات المتوقّع (CSV)
الكود يكتشف الأعمدة تلقائياً. أحد الشكلين:

**تيك (الأفضل والأدق):**
```
time,bid,ask
2021-01-04 00:00:01.123,1898.21,1898.45
```

**أو شموع دقيقة OHLC (بديل تقريبي):**
```
time,open,high,low,close
2021-01-04 00:00:00,1898.3,1898.9,1898.1,1898.7
```

## ⚠️ خطوة حرجة قبل التشغيل
افتح `analyze_gold_time.py` واضبط **`SOURCE_TZ`** على **توقيت السيرفر في ملفك**:
- بيانات Dukascopy غالباً `"UTC"`.
- بعض البروكرات `"Etc/GMT-2"` أو `"Etc/GMT-3"`.

خطأ في هذه القيمة = خطأ في كل التحليل (راجع "مصيدة الوقت/DST" في PLAN.md).

## القيم القابلة للضبط (رأس السكربت)
| القيمة | الافتراضي | المعنى |
|---|---|---|
| `MOVE_THRESHOLD` | 5.0 | الحركة المطلوبة بالدولار |
| `PURITY_THRESHOLD` | 3.0 | أقصى ارتداد عكسي مسموح |
| `SUCCESS_RATE` | 0.90 | عتبة الدقيقة الفائزة |
| `MIN_SAMPLES` | 200 | أقل عدد عينات مقبول |
| `TIMEFRAMES` | [1,5,15] | الفريمات |

## قراءة النتائج
ركّز على عمود **`oos_rate`** (النسبة في الاختبار خارج العينة): الدقيقة الحقيقية تبقى
≥ 90% فيه أيضاً، أما "الحظ" فينهار. وراجع `year_stability_*.csv` للتأكد من الثبات السنوي.
